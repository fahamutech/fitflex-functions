# Events S6 backend contract (portal and mobile)

Source of truth for the shapes below: the route `description` strings in `functions/events-results.mjs`, `events-runs.mjs`, `events-rewards.mjs`, `events-admin-rewards.mjs`, `events-medal-art.mjs`, `events-organizer-api.mjs`, and the specs in `specs/events-s6-*.specs.mjs`. Design: `docs/design/events-s6-runs-results-medals-rewards.md` (parent repo). Everything is dormant: every route answers `404 {"error":"feature_disabled"}` until its flag is on.

## Conventions
- Errors: `{ "error": "<code>", ...extra }`; `X-Request-Id` on every response; 5xx carries `requestId`. 429 carries `retryAfterSeconds` and `Retry-After`.
- Whole-number times in **milliseconds**, instants ISO UTC, money fields do not exist (rewards are digital, `valueTzs` is always `null`).
- Every organizer/admin/member **write** needs header `Idempotency-Key` (8-100 chars) except where noted; a replay returns the first answer with `200` and `Idempotent-Replayed: true`; the same key with another body is `409 idempotency_key_reused`.
- Cursor pagination `{ items, nextCursor }`, `limit` default 50, max 200.
- Flags (all off): `EVENTS_RESULTS`, `EVENTS_RUNS` (needs RESULTS), `EVENTS_RESULTS_PUBLIC` (needs RESULTS), `EVENTS_REWARDS` (needs RESULTS), `EVENTS_MEDAL_ART` (needs REWARDS); each also needs `EVENTS_MODULE` and `EVENTS_REGISTRATION`.
- `GET /events/options` gains `results: { enabled, runs, public, rewards, medalArt }` and `runs: { toleranceBps, maxDaysAfter }`. Read availability from there.

## Stages (derived on the server, never by clients)
`stage`: `none | provisional | official | corrected | disputed | disqualified | rejected`. Labels EN/SW are the client's.

### Medal artwork (needs EVENTS_MEDAL_ART)
- `POST …/medal-templates/:templateId/art` - **raw image body** (not JSON, not multipart); header `Idempotency-Key`; query `confirmationVersion` (required; current text is in `GET medal-templates → artConfirmation` and in the 409), `altEn?`, `altSw?`. `201 { art: { id, templateId, eventId, status: "live", revision, width, height, altText, source: "custom", confirmedAt, createdAt } }`. Errors: `400 svg_not_allowed unsupported_file_type animated_not_allowed image_too_large image_too_small not_square{width,height} corrupt_image no_file_provided raw_body_required`; `409 confirmation_outdated{current} file_not_allowed event_cancelled`; `413 payload_too_large`; `429 rate_limited{retryAfterSeconds,scope,limit,max}`; `503 busy`. The portal must crop to a square >= 512 px, <= 2 MB, before sending.
- `PATCH …/art { altText: { en?, sw? } }`, `DELETE …/art → { removed: { artId } }`, `GET …/art/preview?w=240|480 → image/webp`.
- Member/staff/admin file: `GET /events/medal-art/:artId/file?variant=m512|m256|m128` - **bearer token required** (use an authenticated fetch + `Image.memory`; `Image.network` without headers will 401). `image/webp`; `404` for anyone not allowed, for removed/taken-down art, and for `variant=master`; on 404 show the built-in design from `MedalAward.art.artKey`.

## Admin (portal admin, scope `events`)
- `GET /admin/events/:id/results/summary`, `GET /admin/events/:id/results` - same shapes as organizer, read only.
- `POST /admin/events/:id/results/:resultId/correct|disqualify` - organizer bodies, `note` 10-300 **required**, `expectedRevision` required; `POST /admin/events/:id/results/disputes/:disputeId/resolve` only when open > 7 days or the organizer is not active (`409 organizer_can_resolve` otherwise).
- Reward desk (EVENTS_REWARDS): `GET/POST /admin/reward-definitions`, `PATCH /admin/reward-definitions/:id`, `POST …/:id/activate|pause|end` → `{ definition }`; `RewardDefinition = { id, title: { en, sw }, triggerType: event_finish\|medal\|achievement, triggerEventId, triggerRef, redeemMode: certificate\|perk, terms: { en, sw }, startsAt, endsAt, capTotal, capPerUser, eligibility: { categoryIds? }, expiryDays, reversalPolicy: revoke_unredeemed\|revoke_all, perUserCooldownDays, fundingNote, valueTzs: null, issuerType: "fitflex", status: draft\|active\|paused\|ended, capUsed? }`. `422 value_not_allowed_yet` for any `valueTzs`, `422 issuer_not_allowed`, EN **and** SW required for title and terms.
- `GET /admin/reward-ledger?userId&definitionId&entryType` → `{ items: [{ id, userId|null, member, anonymised, entryType, definitionId, units, sourceType, reverses, occurredAt }], nextCursor }`; `GET /admin/reward-summary` → `{ items: [{ definitionId, earned, redeemed, expired, reversed, capUsed, needsReview }], mostEarnedThisWeek: [{ userId, count }] }`.
- `POST /admin/reward-redemptions/lookup { code }` → `{ redemption: { id, definitionId, title, member, status, expiresAt, redeemedAt, needsReview } }`; `POST …/:id/redeem { note? }`, `POST …/:id/cancel`; `GET /admin/event-award-tasks?state=failed`, `POST …/:id/retry`.
- Medal art (EVENTS_MEDAL_ART): `GET /admin/medal-art?reviewState&status&cursor` → `{ toReview, items: [art + { eventTitle, organizerName, tier, categoryName, reviewState, confirmationVersion, organizerTakedowns30d, highlightOrganizer }], nextCursor }`; `GET /admin/medal-art/:id/preview?w=240|480`; `POST …/:id/reviewed`; `POST …/:id/take-down { reason: inappropriate\|rights\|other_brand\|person_request\|quality\|other, note? }`; `POST /admin/events/:id/medal-templates/:templateId/art` (raw body, confirmation `2026-10-29.s6admin1`).

## Member app
- `GET /me/event-registrations/:id/result` →
```json
{ "registrationId":"erg_…","eventId":"evt_…","eventTitle":"…","eventType":"road","categoryId":"evc_…","categoryName":"10K","distanceMeters":10000,"bibNumber":"1001",
  "stage":"official","viewer":"participant",
  "result":{"id":"eres_…","revision":1,"finishStatus":"finished","verificationStatus":"verified","sourceType":"timing_provider","sourceLabel":"ChipTime Ltd","netElapsedMs":3000000,"gunElapsedMs":null,"elapsedMs":3000000,"overallRank":1,"categoryRank":1,"finishersInCategory":4,"withinCutoff":null,"verifiedAt":"…","correctedAt":null,"reasonCode":null,"correctionNote":null,"personalBest":{"isPersonalBest":true,"previousBestElapsedMs":null,"basis":"same_distance_and_route_type"}},
  "release":{"stage":"official","releasedAt":"…"},
  "dispute":{"id":null,"status":null,"createdAt":null,"resolvedAt":null,"resolutionNote":null,"canRaise":true,"windowEndsAt":"…"},
  "visibility":{"current":"standard","canChange":true,"allowed":["standard","bib_only","hidden"],"reason":"ask|minor (optional)"},
  "runLinks":[RunLink],"medals":[MedalAward],"rewardsEarned":[] }
```
  `result` is `null` while `stage` is `none`. A purchaser after the claim gets only `{ …header, stage, viewer: "purchaser_status_only", finishStatus }`. `personalBest` is `null` unless official; the first result at a distance counts as a personal best (`previousBestElapsedMs: null`). `rewardsEarned` is reserved and returns `[]` (the wallet is `GET /me/event-rewards`).
- `GET /me/event-results` → `{ items: [{ registrationId, eventId, eventTitle, eventStartsAt, categoryName, distanceMeters, bibNumber, finishStatus, stage, elapsedMs, overallRank, categoryRank }], nextCursor }`.
- `PUT /me/event-registrations/:id/results-visibility { visibility }` → `{ visibility }`; `422 visibility_not_allowed` (minor choosing standard).
- `POST /me/event-registrations/:id/result/disputes { reasonCode: time_wrong\|not_my_result\|wrong_category\|missing_split\|dq_challenge\|other, note? }` → `201 { dispute: { id, status: "open", createdAt } }`; `409 dispute_open dispute_window_closed no_result`; `429 rate_limited` (5 a day). `DELETE …/disputes/:disputeId` → `{ dispute: { id, status: "withdrawn" } }`.
- `GET /events/:eventId/results?categoryId&q&cursor&limit` (signed in; EVENTS_RESULTS_PUBLIC) → `{ event: { title, eventType, timezone }, release: { stage, releasedAt }, categories: [{ id, name, distanceMeters, stage }], items: [{ rank, bibNumber, displayName, elapsedMs, finishStatus, stage, sourceType, badges: ["corrected"\|"under_review"] }], mine: { rank, bibNumber }|null, nextCursor }`. `displayName` is `"Asha M."` or `"Runner"` (show "Runner {bib}"); hidden people are absent; DNF/DNS/DQ rows have `rank: null, elapsedMs: null`.
- Runs (EVENTS_RUNS): `POST /me/event-registrations/:id/runs { clientRef, segments, notes?, shareWith? }` → `201 { link: RunLink, activity, result: null\|{ id, revision, verificationStatus, finishStatus, elapsedMs } }` (replay with the same `clientRef`: `200`); `POST …/run-links { activityId }` + `Idempotency-Key` → `201 { link, result }`; `GET …/run-links` → `{ items: [RunLink] }`; `DELETE …/run-links/:linkId` → `{ unlinked: { id } }`. `RunLink = { id, linkType: "evidence"\|"event_run", matchStatus: pending\|matched\|rejected, distanceMeters, movingSeconds, elapsedMs, flags: [], activityId, startedAt, canUnlink }`. A refused create records nothing, so the app then saves the run with `POST /me/activities/runs`. Errors: `422 run_outside_window{window} distance_too_short{measuredMeters,requiredMeters} activity_not_recorded_in_app`; `409 run_already_linked activity_already_linked evidence_limit link_locked linking_closed event_cancelled ticket_revoked registration_not_confirmed result_exists`; `404 registration_not_found activity_not_found`; `429 rate_limited`.
- Medals/achievements (EVENTS_REWARDS): `GET /me/achievements` → `{ medals: [MedalAward], achievements: [{ id|null, key, title: { en, sw }, status: "awarded"\|"locked", awardedAt, progress: { current, target } }], removed: [{ kind: "medal"\|"achievement", id, title, reasonCode, revokedAt }] }`.
  `MedalAward = { id, eventId, eventTitle, categoryName, templateId, tier, name: { en, sw }, description: { en, sw }, art: { source: "custom"\|"builtin", artId, revision, artKey, altText }, status: "awarded"\|"revoked", awardedAt, revokedAt, reasonCode, resultSummary: { rank, elapsedMs } }`.
- Wallet: `GET /me/event-rewards` → `{ available: [{ definitionId, title, terms, units, nextExpiry, redeemMode, canClaim }], redemptions: [{ id, definitionId, title, status: reserved\|redeemed\|cancelled\|expired, redeemMode, code, expiresAt, redeemedAt }], expired: [{ definitionId, title, expiredAt }] }`; `GET /me/reward-ledger` → `{ items: [{ id, entryType, rewardDefinitionId, titleOf, units, sourceType, sourceLabelCode, occurredAt, reverses }], nextCursor }` (no balance, nothing called points); `POST /me/reward-redemptions { rewardDefinitionId }` + `Idempotency-Key` → `201 { redemption: { id, definitionId, status, code, expiresAt, redeemedAt, certificate? } }` (`409 not_enough_units reward_unavailable`, `503 rewards_unavailable`); `GET /me/reward-redemptions/:id`. Perk `code` is `FFR-XXXXXXXX`, shown while `reserved`.
- Additive: `GET /me/event-registrations` rows and `GET /me/event-registrations/:id` gain `resultStage`, `resultsVisibility`, `medalsCount` (the masked purchaser view gets `resultStage` only); `GET /events/:id` gains `results: { stage, releasedAt, categories: [{ id, stage }] }`.

## Organizer API (`/v1/organizer`, API clients)
Scopes `results:read`, `results:write` (both need `registrations:read`; `results:write` can only submit provisional results). `GET /events/:eventId/results`, `GET …/results/releases`, `POST …/results/imports` (`?dryRun=true`, `Idempotency-Key`, max 500 rows, not atomic; per row `{ clientRef, ok, resultId, action: created\|revised\|unchanged\|null, error }`). OpenAPI: `docs/api/organizer-api-v1.openapi.json`. `409 event_not_open_for_results` here (organizer portal routes answer `422`).

## Webhooks (also need EVENTS_WEBHOOKS)
`result.verified { registrationId, resultId, revision, finishStatus }`, `result.published { eventId, categoryId|null, stage, releasedAt, resultCount }`, `result.corrected { registrationId, resultId, revision, previousRevision, finishStatus, material: true }`, `result.disputed { registrationId, resultId, disputeId, status }`. No names, times or contact data; order is not guaranteed, use `revision`.

## Notifications (types; `data.route` deep link, `data.titleEn/Sw`, `data.essential`)
`event_result_published` (optional), `event_result_corrected` (essential), `event_result_rejected` (essential), `event_dispute_update` (essential), `event_medal_awarded` (optional), `event_medal_revoked` (essential), `event_reward_earned` (optional), `event_reward_reversed` (essential), `event_medal_art_taken_down` (organizer owners/admins, essential). Releases above `EVENTS_RESULTS_PUSH_MAX` recipients are in-app only.

## Account deletion (`DELETE /me`)
Ledger rows and redemptions are anonymised (kept, user removed). An organizer owner gets `409 { error: "organizer_owner", message, messageSw }`.
